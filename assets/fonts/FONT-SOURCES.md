# PodThings Sans font sources and licensing

PodThings Sans combines rasterized DejaVu Sans glyphs with GNU Unifont /
UnifontEX Mono bitmap fallback. Modified fonts use the new family name
PodThings Sans. The complete matching source release includes the original
font sources and the generator.
